GERENCIADOR DE CHAVES DE BADMINTON MARÍLIA — V2

Abra index.html no Chrome/Edge/Firefox.

NOVIDADES DESTA VERSÃO
- Chave eliminatória visual inspirada no modelo enviado, com 16 posições e rodadas.
- Resultados são digitados diretamente nas partidas.
- Ao salvar o vencedor, ele avança automaticamente para a próxima rodada.
- Disputa de terceiro lugar ou dois terceiros lugares.
- Gênero do atleta: somente Masculino/Feminino.
- Gênero Mista existe somente na categoria.
- Categorias podem ser Simples ou Duplas.
- Duplas são montadas com exatamente dois atletas.
- Dupla masculina: dois homens.
- Dupla feminina: duas mulheres.
- Dupla mista: um homem + uma mulher.
- Os dois atletas de uma dupla podem ser de equipes diferentes.
- O sistema tenta afastar participantes da mesma equipe nas primeiras rodadas.
- Logo do Badminton Marília é fixa na aplicação e na impressão; não é solicitada ao usuário.
- Layout responsivo para celular.
- Backup e restauração em JSON.
- Impressão/PDF usa a logo fixa.

IMPORTANTE
Os dados são salvos no localStorage do navegador. Exporte backups JSON periodicamente.
Para PDF, use Imprimir / PDF e selecione Salvar como PDF.

A imagem original enviada pelo usuário foi convertida para PNG com fundo branco transparente e salva
como logo_transparente.png. A imagem modelo da chave foi usada como referência visual; a aplicação
gera a chave dinamicamente em HTML/CSS, em vez de depender da imagem estática.
